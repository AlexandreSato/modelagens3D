# 3D Models

A collection of 3D-printable models designed for practical use and shared as STL files.

## Models

### 1. Toyota Corolla E120 Wheel Center Cap

**File:** [`Toyota_Corolla_E120_Brad_Wheel_Center_Cap.stl`](./Toyota_Corolla_E120_Brad_Wheel_Center_Cap.stl)

3D-printable wheel center cap for the 2006 Toyota Corolla Fielder. May also fit other Toyota Corolla models, including the Brazilian-market Corolla known as "Brad". Fitment should be verified before printing.

### 2. Acoustic Guitar Bridge Pin

**File:** [`acoustic_guitar_pin.stl`](./acoustic_guitar_pin.stl)

3D-printable tapered bridge pin for acoustic guitars. Designed with a conical profile and defined dimensions for a precise fit. Compatibility with a specific guitar should be verified before use.

| Specification | Value |
|---|---:|
| Overall length | 25 mm |
| Larger diameter | 5.8 mm |
| Smaller diameter | 4.9 mm |
| Taper angle (per side) | 1.031° |
| Included taper angle | 2.062° |

**Note:** Check the dimensions of your original bridge pin and bridge before printing. Fit may vary between guitar models.
